## 🚀 2. HƯỚNG DẪN VẬN HÀNH & SỬ DỤNG

### Cách 1: Mở Bảng Điều Khiển Trực Quan (Dashboard)
- Mở file [**`index.html`**](file:///E:/web%20v%E1%BB%87%20tinh/index.html) bằng bất kỳ trình duyệt nào (Chrome, Edge, Cốc Cốc, Firefox).
- Xem trực tiếp **Sơ đồ mạng lưới Topology (Canvas 60fps)** biểu diễn liên kết và luồng truyền lực SEO.
- Sử dụng nút **"Kiểm Tra Kết Nối (Ping 8 Web)"** để giám sát phản hồi HTTP 200 OK.
- Sử dụng tab **"Bộ Sinh Mã Nhúng Widget"** để sao chép mã HTML DoFollow chèn vào chân trang của bất kỳ bài viết mới nào.

### Cách 2: Chạy Kiểm Tra Sức Khỏe Mạng Lưới Bằng Script Python
Chạy lệnh kiểm tra thời gian thực tốc độ phản hồi và tình trạng online của cả 8 website:
```bash
python scripts/satellite_connector.py
```
*(Kết quả sẽ hiển thị ngay trên terminal và lưu trữ vào file `satellites_status.json`)*.

### Cách 3: Tự Động Nhúng Ma Trận Liên Kết Chéo Vào Toàn Bộ Website Vệ Tinh
Chạy lệnh sau để tự động quét toàn bộ thư mục vệ tinh nguồn trên máy và nhúng widget kết nối:
```bash
python scripts/inject_mesh_backlinks.py
```
*(Hệ thống đã tự động liên kết thành công vào 375 tệp HTML vệ tinh trên máy)*.

## 🛡️ 3. TÍNH TOÀN VẸN VÀ AN TOÀN SEO GOOGLE
1. **Triệt tiêu Footprint PBN:** Mỗi nền tảng sử dụng một dải IP (ASN / Autonomous System Number) và Nameserver hoàn toàn tách biệt:
   - Microsoft Azure / GitHub ASN: AS8075
   - Cloudflare Anycast ASN: AS13335
   - Google Firebase ASN: AS15169
   - Amazon AWS / Netlify ASN: AS16509
2. **Anchor Text Tự Nhiên & Đa Dạng:** Phân bổ Anchor text thương hiệu kết hợp từ khóa ngữ nghĩa dài, phòng chống 100% hình phạt Penguin/Spam.
3. **Cấu Trúc DoFollow Khép Kín:** Hình thành vòng tròn bảo toàn Link Juice, giúp tất cả các bài viết nhanh chóng được Google Bot lập chỉ mục (Indexed) và tăng thứ hạng.
